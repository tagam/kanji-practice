# かんじ れんしゅう（漢検10級）

小学1年生の漢字80字を、ゲーム感覚で練習するアプリです。`index.html` をブラウザで開くだけで動きます。

- ステージは「いちまると はじめよう！わくわく漢検 10級」の 1しゅうめ〜5しゅうめ・カテゴリの順番
- 問題は漢検10級の本番と同じ7種類（よみ・かきじゅん・ちがう よみ・ただしい よみ・ひらがな1じ・なかまの かんじ・かきとり）
- もぎテスト（大問ごとの点数と、150点満点に直した点数）
- てがきモード、かんじマップ、ガチャ・カードずかん
